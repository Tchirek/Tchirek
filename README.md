# This is Tchirek

New to everything.

## Focus

I mostly build small self-hosted tools, the privacy-first kind I can run myself. Right now most of them live on Cloudflare (Workers, R2, D1), with a small local program that does the syncing.

- [NormalPics](https://github.com/Tchirek/normalpics): private-first photo hosting on R2/D1 with a local sync daemon. The one I work on most.
- [NormalDocs](https://github.com/Tchirek/normaldocs): document sharing, with R2 upload and a preview pipeline.
- [pr1nt](https://github.com/Tchirek/pr1nt): a self-hosted print station for my print shop, written in Rust.
